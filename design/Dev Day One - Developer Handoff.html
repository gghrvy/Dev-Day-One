13 · Implementation Notes

Fonts — load via Google Fonts
Inter: 400, 500, 600, 700, 800, 900
JetBrains Mono: 400, 500, 600
/* Never use Arial, Roboto, or system-ui as a primary face */
Layout — no icon rail
The original 44px icon rail + 168px context panel are replaced by a single 220px sidebar. The layout is display: grid; grid-template-columns: 220px 1fr at root. Sidebar is position: sticky; top: 0; height: 100vh.
Navy not black — avoid near-black hex values
Do NOT use #09090B, #0C0C0E, or #18181F from the old palette. Minimum base is #080D1A.
Borders — use rgba, not hex
All borders should be rgba(120,140,200,0.09) (default) or rgba(120,140,200,0.18) (stronger). This gives the navy-blue tint to separators rather than neutral gray.
AI-generated content — always indigo
Any content generated by AI (chat responses, architecture graph, pattern cards, ADRs, impact analysis) uses #6366F1 as its accent. This creates a consistent "AI authored" signal across the app.
Landing page animations
Hero uses pure CSS animations: blobA/B/C (14–22s ease-in-out infinite), chipRise (linear, 11–17s per chip), dotPulse for live repo indicator, shimmerBtn for CTA sweep. Chat loop is driven by React state with per-step timeouts.
